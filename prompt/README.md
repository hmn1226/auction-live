# プロンプトフォルダの使い方

このフォルダは、開発タスクを明確に記述し、効率的に実装するためのマークダウンファイルを管理するためのものです。

## 使用方法

1. `task_template.md` をコピーして新しいマークダウンファイルを作成します
   ```bash
   cp task_template.md my_new_task.md
   ```

2. 作成したファイルを編集し、タスクの詳細を記入します
   - テンプレートの各セクションに沿って、必要な情報を記入してください
   - コメント（`<!-- -->` で囲まれた部分）は削除してください

3. タスクの実装を依頼する際に、作成したマークダウンファイルを参照します
   ```
   prompt/my_new_task.md に記載したタスクを実装してください
   ```

## 記述のポイント

### 効果的なタスク記述のために

- **具体的に記述する**: 曖昧な表現を避け、具体的な要件を記述してください
- **優先順位を明確にする**: 複数の機能がある場合は、優先順位を付けると実装の順序が明確になります
- **制約条件を明記する**: 技術的な制約、パフォーマンス要件、セキュリティ要件などを明記してください
- **期待される結果を詳細に**: 完了条件を明確にすることで、タスクの完了判断が容易になります

### 参考例

`task_example.md` には、タスク記述の具体例が含まれています。このファイルを参考にして、効果的なタスク記述を行ってください。

## その他の注意点

- 大きなタスクは、複数の小さなタスクに分割することをお勧めします
- 関連するタスク間の依存関係がある場合は、それを明記してください
- 実装中に質問や不明点がある場合は、マークダウンファイルを更新して詳細を追加することも可能です
